# Lase Web ID - Dynamic Company Profile & Web Application CMS Engine

Aplikasi Web Resmi **Lase Web ID** (Software Development Agency) yang didirikan oleh **Elisia Lase** (Lulusan Teknik Informatika). 

## Struktur Folder Proyek Deployment:
```text
lase-web-id/
├── index.html         # Public Frontend Landing Page & Interactive UI
├── css/
│   └── style.css      # Glassmorphism Visual Transitions & Custom Styling
├── js/
│   └── script.js      # Core Logic Engine, Canvas Particle, & Admin Dashboard System
├── sitemap.xml        # SEO Google Search Configuration
├── robots.txt         # Search Engine Crawler Guide
└── README.md          # Dokumentasi Proyek Deployment
```

## Fitur Unggulan:
1. **Frontend Interactive & Visual Transitions**: Efek partikel grafis interaktif pada background canvas.
2. **Dynamic Admin Dashboard CMS**: Login terproteksi (`lasewebid@gmail.com` / `Lasewebid123456789`).
3. **Founder & Biodata Publisher**: Pengaturan biodata **Elisia Lase** dan foto profil dari lokal storage.
4. **App Release Manager**: Rilis showcase aplikasi web baru langsung dari panel admin.
5. **Interactive Budget Engine & WA Order**: Kalkulator biaya + penawaran tawar-menawar harga otomatis.
6. **SEO Optimized**: Dilengkapi Schema.org JSON-LD, sitemap.xml, dan meta tag komprehensif.

## Cara Deployment ke Vercel / Netlify / GitHub Pages:
1. Ekstrak file **`lase-web-id-ready-to-deploy.zip`**.
2. Upload seluruh isi folder ke repositori GitHub Anda.
3. Hubungkan repositori ke **Vercel** atau **Netlify**.
4. Aplikasi web Anda langsung Rilis dan Live secara otomatis!
